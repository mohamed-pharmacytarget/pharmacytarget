# PharmacyTarget — نسخة تشغيلية قابلة للنشر

تطبيق ويب عربي (RTL) لإدارة أهداف وأداء صيدلية — فرع واحد أولًا.
البيانات **متزامنة بين كل الأجهزة** لأنها محفوظة في قاعدة بيانات SQLite على الخادم،
والباسوردات **مشفرة (bcrypt) على الخادم فقط** ولا توجد أي باسورد في كود الواجهة.

أعلى الواجهة الآية الكريمة:
> وَمَن يَتَّقِ اللَّهَ يَجْعَل لَّهُ مَخْرَجًا وَيَرْزُقْهُ مِنْ حَيْثُ لَا يَحْتَسِبُ

## الحسابات الافتراضية (تُزرع تلقائيًا أول تشغيل)

| الدور | اليوزر | الباسورد |
|---|---|---|
| المالك | `owner` | `123456` |
| مدير الفرع | `manager` | `123456` |
| موظف (لوحة موحدة، الموظف يختار اسمه من جوه) | `employee` | `1234` |
| Mohamed — كل الصلاحيات (مخفي عن المالك والمدير) | `mohamed` | `mm@1234` |

> ⚠️ **غيّر كل الباسوردات فورًا بعد أول دخول** من لوحة Mohamed (قسم "تغيير باسورد أي حساب").

## المميزات

- تارجت الفرع الشهري: مبيعات 2,000,000 جنيه / فواتير 5,000 / تكويد 1,000 / توصيل 500 (قابل للتعديل من لوحة المدير).
- إضافة موظف من نموذج `Add Employee` واحد لكل الموظفين: اسم، يوزر، باسورد، تارجت شهري (مبيعات + فواتير + تكويد فقط — التكويد هو نفسه العملاء الجدد، ولا يوجد حقل طلبات)، مع إضافة/حذف بنود خاصة بكل موظف.
- التارجت الشهري يتقسم تلقائيًا على أيام العمل (بدون الجمعة) في لوحة الموظف: مطلوب شهريًا، مطلوب يوميًا، ما حققه، المتبقي.
- تسجيل نتائج اليوم بعد الشيفت في لوحة كل موظف (مبيعات/فواتير/تكويد/توصيل/قيمة Preferred) مع تقرير نهاية يوم: حقق المطلوب أم لا + مطلوب الغد، وتظهر فورًا في لوحة المدير.
- تقارير شهرية لكل موظف وللمبيعات والفواتير مع متوسط قيمة الفاتورة، ومؤشر أداء مركب مع التصنيف والسبب، وتوقعات، وتنبيهات، وقسم "مشاكل ظاهرة في التقارير وحلولها" يُكتشف تلقائيًا من الأرقام، وتصدير CSV.
- Smart Performance Coach، وسجل تعديلات، ونسخ احتياطي/استعادة لقاعدة البيانات.
- رفع تقرير مبيعات شهري وتقرير مبيعات أصناف (Excel أو CSV) على صفحة المدير والمالك، مع تحليل: حققنا التارجت ولا لأ وبنسبة كام.
- Preferred List: المدير يرفعها ويعدلها دوريًا، تظهر تلقائيًا عند كل الموظفين، وكل موظف يشوف بشكل دوري (يومي/شهري) حقق منها بقيمة قد إيه، وتحليل شيت الأصناف آخر الشهر لكل موظف.
- لوحة Mohamed فقط: كل المستخدمين، تغيير باسورد أي حساب، قسم "طلب تعديل"، وزر واتساب ينسخ رسالة تبدأ بـ "أنا محمد، جاي من تطبيق PharmacyTarget".
- كتالوج تشغيل داخل التطبيق فيه كلام جاهز للعرض أمام الإدارة.

## التشغيل محليًا

```bash
npm install
npm start
```

ثم افتح: http://localhost:3000

قاعدة البيانات تُنشأ في `data/pharmacytarget.db` وتُزرع الحسابات والتارجت تلقائيًا أول مرة.

## النشر على الإنترنت — لينك عام (Render — مجاني)

Render هو الخيار المفضل لأن الملف `render.yaml` موجود في المشروع وبيظبط كل حاجة.

1. ارفع المشروع على GitHub:
   - أنشئ Repository جديد على github.com (خاص أو عام).
   - من جهازك:
     ```bash
     git init
     git add .
     git commit -m "PharmacyTarget"
     git branch -M main
     git remote add origin https://github.com/USERNAME/pharmacytarget.git
     git push -u origin main
     ```
2. افتح https://dashboard.render.com وسجّل الدخول (ممكن بحساب GitHub).
3. اضغط **New +** ← **Web Service** ← اختر الـ Repository.
4. اختر **Free** plan، وسيتم ملء أوامر البناء والتشغيل تلقائيًا من `render.yaml` (Build: `npm install` — Start: `npm start`).
5. اضغط **Create Web Service** وانتظر البناء (دقيقتين تقريبًا).
6. سيظهر لك لينك عام مثل: `https://pharmacytarget.onrender.com` — هذا هو لينك التطبيق، افتحه من أي جهاز في الصيدلية وسجّل الدخول.
7. **أول خطوة بعد فتح اللينك:** ادخل بحساب `mohamed` وغيّر كل الباسوردات.

> ملاحظة عن الخطة المجانية في Render: الخدمة بتنام بعد 15 دقيقة بدون استخدام، وأول فتح بعد النوم بياخد حوالي 30–60 ثانية. البيانات محفوظة في ملف قاعدة البيانات على القرص؛ لضمان عدم ضياعها عند إعادة النشر، حمّل نسخة احتياطية أسبوعيًا من داخل التطبيق (لوحة المدير/المالك ← "تحميل نسخة احتياطية") واحتفظ بها.

### بديل: Railway

1. افتح https://railway.app وسجّل الدخول بحساب GitHub.
2. **New Project** ← **Deploy from GitHub repo** ← اختر الـ Repository.
3. Railway يكتشف Node تلقائيًا ويشغّل `npm start`.
4. من تبويب **Settings** ← **Networking** ← **Generate Domain** للحصول على لينك عام.
5. أضف متغير بيئة `SESSION_SECRET` بقيمة عشوائية طويلة من تبويب **Variables**.

## تغيير الباسوردات

من داخل التطبيق: لوحة Mohamed ← "تغيير باسورد أي حساب" ← اكتب اليوزر والباسورد الجديد.
أو احذف ملف `data/pharmacytarget.db` وأعد التشغيل لإعادة زرع الحسابات الافتراضية (سيضيع كل البيانات — استخدمها فقط قبل بدء الاستخدام الحقيقي).

## النسخ الاحتياطي

- **تحميل نسخة:** لوحة المالك أو Mohamed ← "تحميل نسخة احتياطية" (ملف `pharmacytarget-backup.db`).
- **استعادة نسخة:** لوحة Mohamed ← "استعادة من ملف" واختر ملف قاعدة البيانات.
- **قاعدة ذهبية:** نسخة احتياطية أسبوعيًا على الأقل، واحتفظ بنسخة خارج الخادم.

## متغيرات البيئة (اختياري)

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | منفذ التشغيل | `3000` |
| `DB_PATH` | مسار ملف قاعدة البيانات | `data/pharmacytarget.db` |
| `SESSION_SECRET` | سر جلسات الدخول — **غيّره في الإنتاج** | `change-me-in-production` |
| `NODE_ENV` | `production` في النشر | — |
